# dPDF v0.1.15 — development preview

This is a development preview. v0.2.0 remains reserved for the first stable reader.

- Add independent hosted Windows and [private] release-validation lanes with exact-commit
  reports, bounded native MSVC builds and all noninteractive regression corpora.
- Isolate [private] runner/toolchain/data from dGK, publish diagnostics on report-only
  branches, and keep dedicated desktop/native print tests separate from services.

## Validation and remaining work

See docs/VALIDATION.md and docs/validation/ for exact test evidence.
Native Windows printing qualification, full desktop acceptance, cross-platform recovery qualification,
secure region baking and cross-platform review qualification remain unfinished.
This release provides source archives and build instructions; no qualified installer is attached.

dPDF-owned code: Apache-2.0. Third-party components retain their own terms.
