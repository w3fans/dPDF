# dPDF v0.1.7 — development preview

This is a development preview. v0.2.0 remains reserved for the first stable reader.

- Fix Esc cancellation of a pending mark when the main keyboard capture owns the event.

- Add a native Fedora print dialog in an isolated process, with current/range/all
  pages, system page setup and copy controls; retain direct CUPS Quick Print.
- Render print pages at bounded print quality while keeping reader navigation
  responsive, protecting source paths and treating cancellation as cancellation.

## Validation and remaining work

See docs/VALIDATION.md and docs/validation/ for exact test evidence.
Native Windows printing, full desktop acceptance, placement undo/recovery,
secure region baking and revisioned remarks remain unfinished.
This release provides source archives and build instructions; no qualified installer is attached.
