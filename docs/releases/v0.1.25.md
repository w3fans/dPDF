# dPDF v0.1.25 — development preview

This is a development preview. v0.2.0 remains reserved for the first stable reader.

- Scroll the thumbnail list while a page-order drag hovers at its top or bottom
  edge, with viewport-relative drop positions and cancellation checks.

## Validation and remaining work

See docs/VALIDATION.md and docs/validation/ for exact test evidence.
Physical printer/[private] Windows 11 qualification, full desktop acceptance and broader interoperability,
secure region baking and cross-platform review qualification remain unfinished.
This release provides source archives and build instructions; no qualified installer is attached.

dPDF-owned code: Apache-2.0. Third-party components retain their own terms.
