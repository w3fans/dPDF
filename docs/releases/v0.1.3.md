# dPDF v0.1.3 — development preview

This is a development preview. v0.2.0 remains reserved for the first stable reader.

- Add diagnostic simple-overlay copy export with physical mm placement, transparency
  and rotated/cropped page geometry; preserve untouched pages through qpdf assembly.
- Keep ordinary image overlays explicitly separate from secure baking; validate
  multiple marks, input protection and rendered positioning with generated fixtures.

## Validation and remaining work

See docs/VALIDATION.md and docs/validation/ for exact test evidence.
Native Windows printing, full desktop acceptance, graphical mark placement,
secure region baking and revisioned remarks remain unfinished.
This release provides source archives and build instructions; no qualified installer is attached.
