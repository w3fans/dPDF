# dPDF v0.1.4 — development preview

This is a development preview. v0.2.0 remains reserved for the first stable reader.

- Place cleaned signature/stamp images from the studio onto PDF pages, move and resize
  drafts, adjust printed mm sizes/opacity, and export a separate marked copy.
- Keep marks attached to their tabs, confirm discarding unsaved drafts, and prevent
  printing/page operations from silently excluding them; preserve untouched pages.

## Validation and remaining work

See docs/VALIDATION.md and docs/validation/ for exact test evidence.
Native Windows printing, full desktop acceptance, placement undo/recovery,
secure region baking and revisioned remarks remain unfinished.
This release provides source archives and build instructions; no qualified installer is attached.
