# dPDF v0.1.53 — development preview

This is a development preview. v0.2.0 remains reserved for the first stable reader.

- Show a readable, actionable message when a damaged or invalid PDF cannot be opened; retain engine diagnostics in the application log.

## Validation and remaining work

See docs/VALIDATION.md and docs/validation/ for exact test evidence.
Physical printer/Windows test machine Windows 11 qualification, full desktop acceptance and broader interoperability,
secure region baking and cross-platform review qualification remain unfinished.
Source archives and build instructions accompany this preview. Fedora 44/45 RPMs are published only after
successful source builds and package verification; consult the release assets and
[COPR project](https://copr.fedorainfracloud.org/coprs/zvegelj/dpdf/) for available packages.
Check the package source commit and validation record before treating a build as qualified.
