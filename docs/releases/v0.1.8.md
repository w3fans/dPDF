# dPDF v0.1.8 — development preview

This is a development preview. v0.2.0 remains reserved for the first stable reader.

- Add per-tab Undo/Redo for signature/stamp insertion, move, resize, numeric edits
  and removal, with one action per drag, cancellable gestures and bounded image history.
- Keep native text-field Undo separate from mark shortcuts; retain newer drafts
  when an earlier export finishes and retain all history after failed saves.

## Validation and remaining work

See docs/VALIDATION.md and docs/validation/ for exact test evidence.
Native Windows printing, full desktop acceptance, draft recovery,
secure region baking and revisioned remarks remain unfinished.
This release provides source archives and build instructions; no qualified installer is attached.
