# dPDF v0.1.9 — development preview

This is a development preview. v0.2.0 remains reserved for the first stable reader.

- Recover unsaved placed marks from bounded local checkpoints containing the opened
  PDF snapshot, physical sizing and cleaned images, even if the source later changes.
- Save checkpoints off the UI thread, protect the store against competing instances,
  offer explicit recover/discard controls and retire drafts after successful export.

## Validation and remaining work

See docs/VALIDATION.md and docs/validation/ for exact test evidence.
Native Windows printing, full desktop acceptance, cross-platform recovery qualification,
secure region baking and revisioned remarks remain unfinished.
This release provides source archives and build instructions; no qualified installer is attached.
