# Development preview delivery status

Product development continues from 0.1.53. The new public source repository
contains a clean current snapshot and does not import earlier private history.
Historical releases remain with the prior repository; they are not relabeled or
republished as new builds here.

The next development preview uses the existing standard patch controller.
Release notes, Fedora 44/45 source builds and Windows installers must identify
the exact new source revision. No package from an earlier source is substituted.
Native desktop and physical printer acceptance remain separate from hosted CI.
